Why Not Simply Send Everything to an LLM?

  • ✓ Zero Numerical Hallucination: All ₹ totals, orders, and % drops are computed by Python math before any phrasing.
  • ✓ Micro-Latency Classification: Local Jev layer executes in <15ms without cloud token costs.
  • ✓ Confidence Guardrails: 0.70 threshold prevents executing uncertain actions on ambiguous queries.

VyaparMitra: Merchant App Use Case

Retail ERP

VyaparMitra is the practical merchant application built on top of this architecture. It receives natural Hindi/English voice and text queries from retail merchants and routes them through this router.

• Query: "Why were my sales low yesterday?"
• Result: Yesterday's revenue was ₹31,200 (a 44.7% drop vs ₹56,400).
